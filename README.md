# TaskGains — Painel de Ganhos em Plataformas de IA

Ferramenta web simples, direta e fácil de usar para acompanhar ganhos com tarefas em plataformas de IA (como Claru, Hub, entre outras) e monitorar metas financeiras.

## 🚀 Recursos
- **Gestão Dinâmica de Plataformas:** Adicione e gerencie plataformas com moedas personalizadas (USD / BRL).
- **Acompanhamento de Metas:** Metas diárias, semanais ou mensais com barra de progresso visual em tempo real.
- **Lançamentos & Contabilidade:** Registro rápido com status (Pendente / Pago), data, valor e observações.
- **Resumo Visual & Totais:** Cards de totais convertidos para BRL, divisão entre Pendente/Pago e gráfico por plataforma.
- **Persistência Local:** Dados salvos automaticamente no LocalStorage do navegador, com suporte a exportação e importação de backup em JSON.

## 🛠️ Tecnologias
- HTML5, Tailwind CSS, JavaScript (Vanilla), Chart.js.
